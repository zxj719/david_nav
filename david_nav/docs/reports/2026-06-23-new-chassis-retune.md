# 新底盘速度区间 + 位置环 PID 重标定报告（2026-06-23）

> 起因：换大电机 + 大轮子 + **更宽轮距(50.5cm)** 的新底盘，旧
> `position_controller.yaml` 参数是旧硬件标定值。用 `/odom` 轮速真值重新表征 +
> 重调。方法 = 开环找速度区间（死区/饱和）→ 闭环调位置环。脚本自写自跑自监控，
> 3×3m 场地、机器人居中、人守急停。

## 0. TL;DR — 最终参数（已写入 `config/position_controller.yaml`）

| 参数 | 旧值 | 新值 | 依据 |
|---|---|---|---|
| `control_rate` | 50.0 | **20.0** | 新 wheeltec `/odom` 实测 **20Hz**，50 让 2/3 tick 拿陈旧 pose |
| `v_max` | 0.18 | **0.20** | 开环无力矩饱和；v_max 由控制+上肢稳定性定（用户要求慢） |
| `w_max` | 0.30 | **0.75** | ★旋转极难起步：持续旋转破缸 ≈0.65，可靠 ≈0.8；0.30 根本转不动 |
| `a_max` | 0.5 | **0.5** | 保守（上肢不稳，降 jerk） |
| `alpha_max` | 1.0 | **0.8** | 角加速柔化（上肢稳定 + 降超调） |
| `rotate_lead` | 0.20 | **0.40** | 闭环扫描：w_max=0.75 停转滑行 ~20°，提前 ~23° 切零 |
| `min_cmd_v` | 0.07 | **0.14** | ★直行死区上升：0.10 不可靠、0.12 仅爬行、0.14 才可靠推进 |
| `min_cmd_w` | 0.24 | **0.55** | ★旋转死区大升：0.24 在新底盘完全转不动 |
| `dist.Kp/Kd` | 1.2/0.1 | **1.2/0.1**（不变） | 闭环直行已达 −1.4/+2.3cm，无需重调 |
| `yaw.Kp/Kd` | 2.0/0.15 | **2.0/0.15**（不变） | 残余 <1°，overshoot 由 w_max/rotate_lead 主导而非 PID |

**一句话结论**：新底盘最大的变化不是“更有劲”，而是 **旋转阻力大增**（宽轮距 +
大轮 + caster）。旋转命令必须整体上抬 2~3 倍才能起步；直行死区也升约一倍。位置环
PID 增益本身不需要动——**超调的真正旋钮是 `w_max` 和 `rotate_lead`**，不是 Kp/Kd。

## 1. 方法与真值

- **真值 = `/odom` `twist.twist`**（轮速编码器速度），不是对 pose 求导。
- 开环：`scripts/chassis_characterize.py` 直发恒定 `Twist` 到 `/cmd_vel`（绕过
  separator/david_move = 纯 plant），每档保持 2s、末 0.7s 取**中位数**（抗 caster
  起步 stick-slip lurch），每档重复 3 次取 min/median/max。
- 闭环：`scripts/pid_sweep.py` 套现有 `position_controller_field_test.py`
  （自带 3×3 安全框看门狗），逐候选换 yaml → 跑单项 → 解析 CSV → 排序。
- 安全：±1.05m 看门狗（越界发零速）、直行 burst 交替方向 + odom 闭环回中、
  全程人守急停。原始 CSV 见 `docs/reports/data_2026-06-23/`。

## 2. 开环表征结果

### 2.1 直行（worst-case caster 预置：档前甩定脚轮）
| v_cmd (m/s) | actual 中位 (m/s) | 结论 |
|---|---|---|
| 0.10 | 0.01–0.14 | 不可靠，1/3 卡死 |
| 0.12 | ~0.034 | 三发都动但 3cm/s **爬行**（深 stick-slip） |
| 0.14 | 0.15–0.19 | **首个可靠真实推进** → `min_cmd_v` |
| 0.20 | 0.21–0.32 | 干净 |
| 0.25–0.50 | ≈cmd，持续上升 | **无力矩饱和**（大电机够劲） |

→ 直行死区下限 **≈0.14**（旧 0.07 会卡死）；无饱和，v_max 由控制/安全决定。
actual 在 0.14–0.25 段常 ≈1.0–1.3×cmd，疑似 wheeltec 固件有低速补偿。

### 2.2 旋转（in-place；最坏=直行后，ALIGN 真实工况）
| w_cmd (rad/s) | actual 中位 (rad/s) | 结论 |
|---|---|---|
| ≤0.20 | ~0 | 死 |
| 0.25–0.30 | 偶发 | 1/3 reps 才 lurch |
| 0.40–0.50 | 0.06 / 偶发 0.58 | lurch 后立即 stall，**方向强不对称** |
| 0.65 | 0.29 (worst 0.06) | 首个“持续转” |
| 0.80 | 0.80 (worst 0.28) | 可靠（最坏重复也转） |

→ 旋转持续破缸 **≈0.65**，可靠 ≈0.80。**比旧底盘高 2~3 倍**。强 stick-slip +
方向不对称（直行后顺/逆 caster 一侧明显更难）。best-case（无预置）也要 0.65 才
持续转——这是底盘固有属性，非预置造成。

## 3. 闭环结果

### 3.1 旋转 overshoot 扫描（`rotate_lead × w_max`，±90°）
| rotate_lead | w_max | 超调中位 |
|---|---|---|
| 0.30 | **0.70** | **21.1°** |
| 0.50 | **0.70** | 19.9° |
| 0.70 | 0.70 | 26.1° |
| any | 0.90 | 33–40° |

**`w_max` 主导超调**（0.70→~20° vs 0.90→~35°）；rotate_lead 在 caster 噪声内
差异小。取 **w_max=0.75**（0.70 超调最低但 ALIGN-后-直行最坏需 ~0.8 才稳；0.75
折中）+ **rotate_lead=0.40**。所有候选 12/12 转动成功、残余 <1°。

### 3.2 直行闭环（v_max=0.20, dist.Kp1.2/Kd0.1, approach_decel0.15）
| 方向 | 残余 | 侧偏 | 超调 |
|---|---|---|---|
| 后退 0.8m | −1.4cm | −0.2cm | 0 |
| 前进 0.8m | +2.3cm | −0.5cm | 0 |

直行精度好、侧偏可忽略、零超调（approach_decel 刹停有效）→ **dist 增益不动**。

### 3.3 全项验收（straight+rotate+pose+repeat，最终参数）
| 项 | 结果 | 验收线 | |
|---|---|---|---|
| straight 0.8m | 残余 −2.8cm，侧偏 +0.8cm，超调 2.9cm | ~2cm | ✓ |
| rotate +90° | 残余 +0.35°，超调 19.0° | <1.15° | ✓ |
| rotate −90° | 残余 +0.68°，超调 22.4° | <1.15° | ✓ |
| pose (turn-drive-turn) | 位置 16.9cm，朝向 −3.28° | ≤20cm/20° | ✓ |
| repeat ×3 散布 | 均值 **20.1cm**，σ 6.0cm，最大 24.4cm | — | caster 受限 |

- **ALIGN-后-直行 全程未卡死** → 印证 `w_max=0.75` 足够（优于 0.70 的选择）。
- 旋转残余 <0.7°，~20° 瞬态超调（设计内，由 rotate_lead 收）。
- **定点重复散布 ~20cm 是 caster 平面噪声（拖尾 + 终转 scrub），非增益问题**——
  这是这台底盘诚实的精度上限，要更准只能治本（固件 break-away 前馈 / 换 caster）。

## 4. 旁证 / 现场观察

- **odom 漂移巨大**：跑完一轮旋转，odom 在 X 上漂了 **>2m**（物理没动这么多）。
  caster 旋转-平移耦合 + 拖尾。位置环按**每目标相对帧**工作，相对精度不受影响，
  但**任何依赖 odom 绝对位置的逻辑都不可信**（这也是建议跑 slam_gt 看真值的原因）。
- **本体臂入雷达视野**：`/scan` 正前方恒 0.39m（base_link ~0.74m），机器人后退
  0.8m 后该回波仍 0.39m → 随车移动 = **自身手臂**（超出 self_filter 本体盒
  X<0.45），非外部障碍。监控障碍时需忽略此自回波。

## 5. 待办 / 风险

- `w_max=0.75` 对 ALIGN-后-直行 最坏工况是折中值；若实跑出现“贴脸转不动”，
  上抬到 0.80（代价：超调 ~28°）。正解是固件做 break-away 前馈。
- 旋转方向不对称未单独补偿；若某向系统性更差，可在核心层按转向给 min_cmd_w 偏置。
- a_max/alpha_max 现按“上肢稳定优先”取保守值；上肢稳了可放宽提速。
