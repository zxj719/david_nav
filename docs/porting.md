# 多机器人支持：当前不承诺

目前用本仓库的只有 David 一台机器人。W46 减法轮撤销了"换机器人只改配置"这一产品承诺：

- `example_diffdrive_config` 是**测试夹具**。它提供一份帧、话题都和 David 不同的虚构机器人配置，
  供沙箱检查和真实 Nav2 接线测试使用，作用是把通用代码里写死的 David 常量找出来。
  它不是受支持的部署目标，也不说明另一台实体机器人已经能用。
- 等第二台真实机器人（例如 David No.2）接入时，再按它的实际差异评审要改哪些地方。
  不要为假设中的机器人提前扩展通用抽象。
- 配置体系计划在 R3 改成"原生 Nav2 参数文件加模式差异文件"。到那时，接入流程以新的配置说明为准。

对测试夹具做离线校验（不启动 ROS，不代表实体机器人可用）：

```bash
navcfg validate --robot example_diffdrive --mode tour
```

现场的接口检查和人工边界见 [runbook.md](runbook.md)。
